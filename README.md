Friday Verdict is a static Black Friday and Cyber Monday deal finder with 35 real deals checked on 27 November 2026, from 6 stores. Every deal carries an honest signal about whether it is genuinely a deal — a true low, a strong deal, or just a routine sale.

## Features

- Text search across all deals
- Filters by category, store, and minimum discount
- Sorting by biggest discount, lowest price, or best verdict
- A detail page for each deal explaining the reasoning behind its verdict
- A mobile-friendly layout

## Running it

Serve the `app` folder with any static server, then open `index.html` in a browser. There is no build step and no network request.

The `main.ts` program in the repository root handles the entry submission: it copies `app` and the screenshots into the output folder and writes `dossier.json`.
